# Carnet Films

Watchlist en PWA (application web installable sur iPhone) : recherche de films et séries, jaquettes,
notes IMDb / Rotten Tomatoes / Metacritic (via OMDb), import d'une liste collée, carnet filtrable.

- Site : https://mehdioptimisationtrash-cyber.github.io/carnet-films/
- Clé gratuite nécessaire : https://www.omdbapi.com/apikey.aspx (saisie dans l'app, gardée sur l'appareil).
- Tests : `npm test` (fonctions pures) ; `npm run serve` puis `python3 tests/e2e/run.py <dossier captures>` (WebKit, faux OMDb).
